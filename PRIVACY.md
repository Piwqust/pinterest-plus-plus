# Privacy Policy

Pinterest Plus Plus does not collect, store, sell, or transmit personal data.

The extension runs only on Pinterest pages. When the user explicitly clicks Copy or Download, it reads the selected media URL from the current page and accesses that Pinterest or Pinimg resource locally in Chrome. Grid width is stored with `chrome.storage.sync`; Chrome may sync that single numeric preference according to the user's Chrome Sync settings.

There are no analytics, advertisements, accounts, tracking identifiers, remote configuration, or third-party servers. Downloaded and copied media remains on the user's device. Removing the extension removes its locally stored settings; synced settings are governed by Chrome Sync.

Pinterest Plus Plus is an independent project and is not affiliated with Pinterest, Inc.
