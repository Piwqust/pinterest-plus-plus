## [1.0.6] — 2026-09-09

### Готовность к ревью: минимальный Chrome и живая кнопка на панели

- **Что:** `minimum_chrome_version` поднят до 111, у иконки на панели появился попап, чтение настроек больше не может уронить content script.
- **Где:** `wxt.config.ts`, `entrypoints/popup/`, `shared/settings.ts`, `tests/settings.test.ts`.
- **Почему:** заявленный Chrome 109 пропускал браузеры, где ключ `world: "MAIN"` ещё игнорируется, а иконка на панели не делала ничего.
- **Было:** `minimum_chrome_version: '109'`, `action` без `default_popup` и без `onClicked`.

### Fixed

- **Chrome 111 вместо 109.** `world: "MAIN"` на манифестном content script читается только с 111. На 109–110 мост к масонри уехал бы в isolated world и ресайз молча не работал — половина продукта без единой ошибки в консоли.
- **`readSettings` больше не отвергается.** Первый `await` в content script был его единственной точкой отказа: профиль с запрещённым sync storage оставался без кнопок и без ползунка, хотя ширина по умолчанию его бы устроила.

### Added

- **Попап без новых разрешений.** Он пишет тот же ключ `tileWidth` в `chrome.storage.sync`, а content script уже слушает `storage.onChanged`, поэтому сетка перестраивается сама. Отвергнут вариант с `tabs` или `activeTab` ради определения текущей вкладки: лишнее разрешение ради косметики удорожает ревью.
- **Потолок ползунка в попапе растягивается под сохранённое значение.** Без этого простое открытие попапа у пользователя с широкими плитками тихо урезало бы его настройку.

## [1.0.5] — 2026-09-09

### Пакет для первой публикации в Chrome Web Store

- **Что:** расширение можно отправлять в Chrome Web Store: ZIP текущей сборки, тексты листинга, обоснования разрешений, политика конфиденциальности как страница, скриншоты и промо-плитки нужного размера.
- **Где:** `store/`, `PRIVACY.md`, `README.md`, `.output/pinterest-plus-plus-1.0.5-chrome.zip`.
- **Почему:** манифест и иконки уже были; без листинга, публичного URL политики и графики дашборд не принимает item. Локальная обработка медиа и `chrome.storage.sync` всё равно считаются handling user data.
- **Было:** README «Load unpacked», короткий `PRIVACY.md`, ZIP без сопроводительного пакета.

### Added

- **Пакет `store/`, а не правка манифеста.** Листинг, политика-HTML и ассеты живут рядом с репозиторием и не попадают в ZIP расширения. В ZIP нечего добавлять для магазина: CWS читает манифест из пакета и поля из дашборда.
- **Политика покрывает локальную обработку.** CWS User Data Policy требует disclosure даже если ничего не уходит на сервер разработчика. Отвергнуто «нам политика не нужна, мы ничего не собираем» — `storage` и чтение URL пина при клике этого достаточно.
- **Скриншоты с реальным CSS контролов, не live Pinterest.** Нужны 1280×800 без чужих пинов и логотипа Pinterest. Отвергнут захват pinterest.com: копирайт чужих пинов и риск, что ревьюер сочтёт это чужим брендом.

### Changed

- **Английский листинг как основной.** UI расширения на английском; русские тексты лежат рядом как опциональная локаль, без `_locales` в пакете. Иначе магазин обещал бы русский продукт, которого в интерфейсе нет.
